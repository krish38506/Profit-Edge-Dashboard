# Profit Edge Dashboard

📊 **Profit Edge Dashboard** is an Excel-based E-commerce Sales Analysis Dashboard designed to enhance sales performance tracking and data-driven decision-making.

## 🔹 Features

- **Profit Analysis** – Gain insights into overall and category-wise profit trends.  
- **Interactive Filtering** – Use slicers to filter data dynamically.  
- **KPI Tracking** – Monitor key performance indicators for better business insights.  
- **Advanced Visualizations** – Includes line charts, bar charts, pie charts, and geographic heat maps.  
- **Category & State-wise Insights** – Analyze product performance across different regions to optimize strategies.  

## 🛠 Tools & Techniques Used

- **Microsoft Excel**  
- **Pivot Tables & Pivot Charts**  
- **Slicers for Dynamic Filtering**  
- **Data Visualization Techniques**  

## 📂 How to Use

1. Open the Excel file in Microsoft Excel.  
2. Use the slicers to filter data by category, region, or other parameters.  
3. Analyze key metrics through interactive charts and tables.  

## 📌 Use Cases

- Sales and profit analysis for E-commerce businesses.  
- Performance tracking of products and regions.  
- Data-driven decision-making for marketing and sales strategies.
